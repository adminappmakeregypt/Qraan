# Qraan — نظام إدارة حلقات التحفيظ

## التشغيل
افتح `index.html` في المتصفح (أو ارفع المجلد على أي استضافة ملفات ثابتة). أول تشغيل يطلب إنشاء حساب المدير.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | تسجيل الدخول (المدير: بريد + كلمة مرور / المحفظ والمشرفة: اسم مستخدم + رقم) |
| `admin.html` + `admin.js` | لوحة المدير: توزيع المحاضرات، محفظين، طلاب، جدول، سجل المحاضرات، رسائل واتساب، إعدادات |
| `teacher.html` + `teacher.js` | صفحة المحفظ: جدوله من المدير، «حضر + التقرير» / لم يحضر لكل محاضرة، عداد محاضراته |
| `supervisor.html` + `supervisor.js` | صفحة المشرفة: تقارير الحصص الجاهزة ← «إرسال للجروب» من واتساب موبايلها، وإحصائيات المحفظين |
| `core.js` | التخزين، المناطق الزمنية، منطق خصم المحاضرات والرسائل |
| `style.css` | التصميم (RTL، متجاوب مع الموبايل) |

## منطق العمل
- «توزيع المحاضرات»: اختر محفظ ← أضف طالب جديد / عيّن طالب حالي / موعد أسبوعي / محاضرة إضافية مرة واحدة / محاضرات للباقة / نقل طالب.
- مواعيد كل طالب تُسجل **بتوقيت بلده**، وتظهر للمحفظ بتوقيت بلده وللمدير بتوقيته (مصر/السعودية/الكويت/الإمارات/الأردن).
- المحفظ يسجل كل محاضرة من جدوله بـ «حضر» أو «لم يحضر» — كل تسجيل يخصم محاضرة (خصم الغياب قابل للتغيير من الإعدادات)، ويمكن التراجع خلال 24 ساعة.
- صفحة «سجل المحاضرات» عند المدير: كل محفظ عمل كام محاضرة، امتى، ولمين — مع فلتر بالشهر وتصدير Excel.
- عند آخر محاضرة: الحالة تتحول «منتهي»، تتوقف الحلقات القادمة، وتُضاف رسالة تذكير بالاشتراك لولي الأمر.
- التجديد من المدير يعيد الحالة «مدفوع» ويضيف محاضرات الباقة.
- رسالة واتساب واحدة فقط: عند تسجيل آخر محاضرة في الباقة تُرسل لولي الأمر تذكير بدفع الاشتراك — تلقائيًا عبر WhatsApp Business API (الإعدادات ← ربط واتساب) أو يدويًا.

## المشرفات والمحفظين والطلاب
- كل محفظ له **مشرفة** (من «تعديل محفظ»، أو من «تعديل مشرفة» ← اختيار المحفظين التابعين لها، أو «+ محفظ جديد تحتها»).
- الطالب بيتبع **مشرفة محفظه تلقائيًا**. ولو محتاج طالب معيّن مع مشرفة تانية: «تعديل طالب ← المشرفة ← (للطالب ده بس)».
- أي تغيير بيسمع في كل حتة فورًا: لو غيّرت مشرفة محفظ، كل طلابه وتقاريرهم (حتى القديمة اللي لسه ما اتبعتتش) بتنتقل لصفحة المشرفة الجديدة.
- المشرفة بتشوف تقارير **طلابها بس** وإحصائيات **محفظينها بس**.

## تقارير الحصص للجروبات
1. المدير يكتب **اسم جروب واتساب** لكل طالب (صفحة الطلاب) ويضيف المشرفات (صفحة المشرفات).
2. المحفظ يضغط «✅ حضر + التقرير» ← يملأ قالب تقرير الحصة (حفظ جديد، مراجعة، الواجب، التجويد، الشرعي، المدة) ← حفظ.
3. التقرير يظهر عند المشرفة في «جاهزة للإرسال» ومعاه اسم الجروب.
4. المشرفة تضغط «📤 إرسال للجروب» ← واتساب يفتح على موبايلها والرسالة جاهزة، واسم الجروب يتنسخ ← تختار الجروب وتضغط إرسال.
5. ترجع للتطبيق وتأكد «✅ اتبعت» ← يتسجل مين بعت وإمتى.
6. صفحة «المحفظين» عند المشرفة و«محاضرات المحفظين» عند المدير: كل محفظ عمل كام محاضرة وكام تقرير اتبعت، بفلتر الشهر.
- شكل الرسالة يتعدل من «الإعدادات ← قالب تقرير الحصة».
- الإرسال يدوي من واتساب المشرفة نفسها (بدون أي أداة غير رسمية) — فمفيش خطر حظر على رقم الأكاديمية.

## قيود النسخة الحالية
- البيانات محفوظة في **متصفح الجهاز** (localStorage) — كل المستخدمين يجب أن يعملوا على نفس الجهاز/المتصفح، أو استخدم التصدير/الاستيراد.
- الإرسال التلقائي يحتاج قالب Utility معتمد من Meta. التوكن يُحفظ في المتصفح — للأمان استخدم خادم وسيط.
